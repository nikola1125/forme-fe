# Formë

> A distinctive dress collection for rent in Tiranë — defined by form.

Marketing and booking site for **Formë**, a dress-rental studio. Built with
[TanStack Start](https://tanstack.com/start) (full-stack React with SSR),
[TanStack Router](https://tanstack.com/router) and
[TanStack Query](https://tanstack.com/query), styled with
[Tailwind CSS v4](https://tailwindcss.com) and [shadcn/ui](https://ui.shadcn.com).

## Tech stack

| Area       | Choice                                                        |
| ---------- | ------------------------------------------------------------- |
| Runtime    | [Bun](https://bun.com)                                        |
| Framework  | TanStack Start + TanStack Router (file-based routes)          |
| Data       | TanStack Query                                                |
| Build tool | [Vite 7](https://vite.dev)                                    |
| Styling    | Tailwind CSS v4 (`@tailwindcss/vite`) + `tw-animate-css`      |
| UI         | shadcn/ui (Radix primitives), lucide icons                    |
| Forms      | react-hook-form + zod                                         |
| Language   | TypeScript                                                    |

## Getting started

```bash
bun install       # install dependencies
bun run dev       # start the dev server at http://localhost:3000
```

## Scripts

| Script                | Description                                            |
| --------------------- | ----------------------------------------------------- |
| `bun run dev`         | Start the Vite dev server (SSR + HMR) on port 3000.   |
| `bun run build`       | Production build → `dist/client` and `dist/server`.   |
| `bun run start`       | Serve the built app (`dist/server/server.js`) on Bun. |
| `bun run serve`       | Preview the built client with `vite preview`.         |
| `bun run lint`        | Run ESLint.                                            |
| `bun run typecheck`   | Type-check with `tsc --noEmit`.                        |
| `bun run format`      | Format the codebase with Prettier.                    |
| `bun run format:check`| Check formatting without writing.                     |

## Project structure

```
src/
  routes/          # File-based routes (__root.tsx is the shell)
  routeTree.gen.ts # Generated by TanStack Router — do not edit
  components/       # App components
    ui/             # shadcn/ui primitives
  hooks/            # Reusable hooks
  lib/              # Utilities, data, error handling
  assets/           # Images
  router.tsx        # Router + QueryClient setup
  server.ts         # Server entry (request handler + error normalization)
  start.ts          # Start instance (request middleware, CSRF)
  styles.css        # Tailwind v4 entry + design tokens
public/             # Static assets served as-is
```

## Adding UI components

This project uses shadcn/ui (see `components.json`):

```bash
bunx shadcn@latest add <component>
```

The `@/*` import alias maps to `src/*`.
